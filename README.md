## 当前项目

### 学生成绩管理系统

这是一个使用 Python 编写的学生成绩管理系统，当前版本为命令行程序，主要功能包括：

- 添加、查询、修改和删除学生
- 使用 JSON 保存学生数据
- 按成绩排序
- 按中文姓名拼音排序
- 统计学生人数、最高分和最低分
- 导出 CSV 成绩单

项目文件包括：

- `student_management.py`：主程序
- `students.json`：学生数据
- `成绩单.csv`：导出的成绩单

这是一个适合练习 Python 基础、数据处理和业务逻辑的项目。后续我会基于它继续学习 Django，并将其升级为 Web 版学生管理系统。
